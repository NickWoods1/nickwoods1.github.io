# Nick Woods

Personal website for `nickwoods1.github.io`.

## Commands

```bash
npm install
npm run dev
npm run build
npm run deploy
```

## Hosting

This is intended to be the GitHub Pages user site at:

```text
https://nickwoods1.github.io/
```

The `deploy` script builds the site and publishes `dist` to the `gh-pages` branch.
